# Pilot 27 — bare-form pronunciation candidates

Exactly the problem set, not a representative sample.

Each lemma has two MP3s:
- `NNN_slug_A.mp3` — candidate A
- `NNN_slug_B.mp3` — candidate B

Content is the **bare citation form only** (what the card front shows).
No genitive, no article, no English gloss.

Mark pass/fail (syllable test or ear). After you pick A/B per index, the full 470 bare-form pack uses those locked tokens and leaves working hyphenated spellings alone.

Core seven from the earlier note:
καί, λόγος, πῶς, πλήν, πείθω, ὀπίσω, κλαίω
